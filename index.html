Sobre Mí

¿Quién soy?

Estudiante de Análisis y Desarrollo de Software en el SENA. Me gusta crear sistemas web útiles, bien organizados y fáciles de manejar para las personas que los usan en su trabajo diario.

¿Qué hago?

Desarrollo aplicaciones web con PHP, MySQL, HTML, CSS, JavaScript y Python. Armo desde las pantallas y la base de datos hasta la descarga de documentos en PDF o Excel y la puesta en marcha en servidores Linux con Docker.

Mi forma de trabajar

Procuro entender bien lo que necesita cada negocio, cuidar los detalles y probar cada función con calma para entregar un sistema claro, seguro y sin complicaciones.
